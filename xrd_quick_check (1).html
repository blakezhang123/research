💎 1) Multi-phase calibration → theoretical peak markers (up to 3 phases)

How to use: click a phase heading to make it the “current phase”, then click a peak on the plot — its 2θ is filled into that phase’s calibration box. Fill in structure and calibration peak for each phase, then click the button below to mark all phases at once — each phase in its own colour, labels include the phase name. For a B2 phase select structure “B2” (ordered BCC, incl. superlattice peaks such as (100); select BCC for disordered BCC). Untick “Enable” for phases you do not need.

📏 2) Crystallite (domain) size — Scherrer / Williamson–Hall

Scope, stated plainly: Scherrer gives the coherent diffraction domain size, not the grain size in the EBSD sense. It is only meaningful for nanocrystalline / heavily deformed material / thin films; when the result is ≳150–200 nm, the broadening is close to the instrumental broadening and the value is essentially set by the instrument — do not report it as a real grain size. The FWHM must come from a peak fit (or the automatic estimate below), not from measuring by eye on the plot — that was the largest source of error in the original version of this tool.

1 peak → Scherrer (assuming no strain); ≥2 peaks → Williamson–Hall: β·cosθ = Kλ/D + 4ε·sinθ, the intercept gives the size, the slope the microstrain, and the fit R² is reported. If R² is low or the intercept is ≤0 the result is not trustworthy — the program will say so explicitly instead of forcing a number.
